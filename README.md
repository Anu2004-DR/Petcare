# 🐾 Pet Care Android Application

## 📌 Project Overview
The Pet Care Application is an Android-based mobile application developed to help pet owners manage pet-related services in one platform.  
The application provides features such as pet adoption, appointment booking, pet product browsing, and account management.

This project was developed using Java, XML, Android Studio, RecyclerView, and SQLite database.

---

# 🚀 Features

- 🐶 Pet Adoption Module
- 📅 Appointment Booking System
- 🛒 Pet Product Store
- 🎁 Offers Section
- 👤 User Account Management
- 📱 RecyclerView-based Dynamic Lists
- 💾 SQLite Database Integration
- 🎨 User-Friendly UI Design
